# 2D·1D MAC 실제 성능 비교

동일 입력·반복 수, 각 1000회 × 5라운드의 호출당 평균 시간 중앙값. 변환은 측정 구간 밖에서 한 번만 수행했다.

| N | 2D ms | 1D ms | 2D/1D | 변환 1회 ms |
| --- | --- | --- | --- | --- |
| 3 | 0.000383 | 0.000262 | 1.459 | 0.001192 |
| 5 | 0.000929 | 0.000614 | 1.514 | 0.001042 |
| 13 | 0.004981 | 0.003686 | 1.351 | 0.003176 |
| 25 | 0.017492 | 0.014197 | 1.232 | 0.007234 |

속도비가 1보다 크면 이번 측정에서 1D가 빨랐다는 뜻이다. 두 구현 모두 O(N²)이고, Python 객체를 담는 리스트이므로 연속 숫자 메모리나 실제 NPU 메모리 최적화를 증명하지는 않는다. 단발 실행에서는 변환 비용도 포함해 판단해야 하며 실행 환경에 따라 결과가 달라진다.
